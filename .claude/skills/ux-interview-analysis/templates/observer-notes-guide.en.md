OBSERVER NOTES — Obsidian + Time Bullet

Every line of your notes gets the time you started writing it (computer clock, to the second). The
analysis uses it to place each note at the right moment of the recording, next to the transcript and
the board steps. Free, no account, Mac and Windows.


SETUP (once, ~5 minutes)

1. Install Obsidian from obsidian.md. No account or licence needed (free for work too).
2. Create a vault, e.g. "UX notes".
3. Settings → Community plugins → Turn on community plugins → Browse → "Time Bullet" → Install → Enable.
4. Settings → Time Bullet (its own page at the bottom of the left sidebar, under Community plugins):
   - Time format: HH:mm:ss
   - Use UTC: OFF. It is ON by default — then every time is shifted against your computer clock.
5. Test: in a new note type -[t] and then SPACE (not Enter — after -[t] Enter does nothing) → it
   turns into "- [14:03:27] " with the current time. From then on just press Enter: every new line
   gets its own time. Compare with your computer clock.


DURING THE SESSION

- One file per session, named by the participant ID, e.g. "S1-U02.md". No participant names.
- When the moderator starts the recording, write the first line: "▶ recording started". All notes
  are aligned to the recording through this line — without it the offset has to be guessed.
- One thought = one line (Enter). The time is set when the line is created.
- Don't rewrite old lines during the session. A correction or addition = a new line starting with
  "correction:".
- Write facts, not conclusions: what they do, what they say, what happens on screen.
- Optional tags at the end of a line: #bug #ux #request #quote #moderation #materials.


AFTER THE SESSION

- Upload the .md file to the participant's folder (where the recording is). Nothing else.
- The analysis converts note times to recording time (via the "▶ recording started" line) and links
  them to the transcript and the board sections.
